# Todo Manager Microservices 🚀

Система управления задачами, построенная на микросервисной архитектуре. Проект разделен на независимые сервисы для работы с пользователями и задачами.

## 🏗 Архитектура системы

Проект состоит из следующих компонентов:
- **Auth Service**: Отвечает за регистрацию и аутентификацию пользователей.
- **Todo Service**: Управляет списком задач, категориями и тегами.
- **PostgreSQL (x2)**: У каждого микросервиса своя изолированная база данных.



## 🛠 Технологический стек
- **Язык:** Go (Golang)
- **ORM:** GORM (с использованием AutoMigrate)
- **БД:** PostgreSQL
- **Контейнеризация:** Docker & Docker Compose

## 🚀 Как запустить проект

Все компоненты системы запускаются одной командой. Убедитесь, что у вас запущен Docker.

```bash
# Сборка и запуск всех контейнеров
